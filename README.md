# Predicting-Cifar_Images-animals-using-CNN
# Dataset

Images: 60,000 (32x32 RGB images)

Train/Test Split: 50,000 / 10,000

Classes: 10 (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck)

# Tech Stack

Python

TensorFlow/Keras

NumPy, Matplotlib

# Model Architecture

Conv2D + ReLU layers for feature extraction

MaxPooling2D for downsampling

Dropout for regularization

Dense + Softmax output layer for 10-class prediction


Test Accuracy: ~70–80% with a simple CNN

Higher accuracy possible with deeper CNN or transfer learning
